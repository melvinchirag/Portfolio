# Parked — photo-to-particles face mask (rejected 2026-07-27)

A first attempt to build the hero mask by sampling Melvins 2D photo into
teal particles. Rejected: a 2D photo cannot become a real sci-fi mask without
3D geometry — it read as "a photo converted to a shader". Superseded by the
Codrops dreamy-particles GPGPU approach using a real 3D cyborg mask model.
Kept for reference. `face.png` is Melvins background-removed portrait.
